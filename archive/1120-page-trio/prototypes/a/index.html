    How to install
    1. Double-click the downloaded .dmg file to open it.
    2. Drag HappyCamper into the Applications folder.
    3. Open HappyCamper from Applications. macOS will say it can't verify the app. Click Done.
    4. Open System Settings › Privacy & Security, scroll down, and click Open Anyway next to the HappyCamper message. Enter your password if asked.
    5. HappyCamper opens, and opens normally from then on.

    macOS asks this about any app that isn't from the App Store, and only the first time. Apple explains it in Open a Mac app from an unknown developer. All of HappyCamper's code is public, and the codebase page explains what it does.

    Not sure which Mac you have? Open the Apple menu › About This Mac. A Chip line that starts with Apple means Apple Silicon. A Processor line that says Intel means Intel.
