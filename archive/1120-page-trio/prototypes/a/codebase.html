HappyCamper

How it's built

What the app is made of, where its code lives, and what it does with your data.

What it does

HappyCamper takes two spreadsheets saved as CSV files, your camper list and your activity schedule. It merges them into one table and gives you filters for finding errors in it.

If you'd rather work in your own spreadsheet tool, export the merged table as a CSV and take it from there.

Your data stays on your computer

A website sends what you enter to someone else's server. HappyCamper is a desktop app, so it runs entirely on your computer.

It never connects to the internet. Data only goes in when you import a file, and only comes out when you export one. Nothing is kept between runs.

Nothing else to install

HappyCamper is written in Java, and each download includes everything it needs to run. It works the same on Mac, Windows and Linux.

Where the code lives

The code is public on GitHub, a site that stores code along with the history of every change. Anyone can read it without an account.

How it was written

I wrote the original version by hand in 2024 and 2025. Since then I've used AI coding tools to improve test coverage and reorganize the code.

No AI system has seen real camper data. Every roster in the codebase was written by hand, or anonymized with NameSwap before it was added.
